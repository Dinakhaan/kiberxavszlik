🛡️
SQL Injectionni bartaraf eting
Barcha ma'lumotlar bazasi so'rovlarida Prepared Statements va parametrlangan so'rovlardan foydalaning. PDO yoki ORM kutubxonalarini qo'llang. Kiruvchi ma'lumotlarni sanitize qiling.
🔒
MySQL portini yoping
UFW yoki iptables yordamida 3306 portni faqat localhost (127.0.0.1) uchun oching. Tashqi tarmoqdan kirish imkonini to'liq bloklang.
🔐
HTTPS majburiy qiling
Let's Encrypt bilan bepul SSL sertifikat oling. Apache .htaccess da barcha HTTP so'rovlarni HTTPS ga yo'naltiring. HSTS header qo'shing.
⬆️
OpenSSH ni yangilang
apt update && apt upgrade openssh-server buyrug'i bilan yangilang. Parol autentifikatsiyasini o'chirib, faqat SSH key ishlatishga o'ting.
📋
Xavfsizlik headerlarini sozlang
Apache konfiguratsiyasiga X-Frame-Options: DENY, X-XSS-Protection: 1; mode=block, Content-Security-Policy va Strict-Transport-Security headerlarini qo'shing.
📁
Directory listing o'chiring
.htaccess fayliga Options -Indexes qo'shing. Barcha papkalarda index.html fayli bo'lishini ta'minlang. /uploads/ papkasiga to'g'ridan-to'g'ri kirishni cheklang.
